# Олег Цапенко — утверждённая концепция

Источник: подробное техническое задание пользователя. Повторное согласование исключено пользователем.

Цель: персональный кинематографический лендинг, знакомство с артистом, прослушивание и заказ через MAX.
Подход: React 19 + TypeScript + Vite, CSS, GSAP/ScrollTrigger. Статический лендинг без сервера и форм. Исходного кода нет. Более тяжёлые 3D-подходы исключены заданием.
Композиция: полноэкранная сцена с текстом в нижней части; вертикальное видео; журнальная биография; четыре направления; широкая атмосферная сцена; один фотоблок; три шага; финальные контакты.
Медиа: четыре PNG и Vid_sax.mp4 существуют. Оригиналы сохраняются; оптимизированные производные отдельно. Telegram отсутствует — поле конфигурации пустое, выдуманной ссылки нет.
Цвета: #090B0E, #15191E, #C9A66B, #E8D4A6, #F5F1E8, #A5A9B0.
Доступность: семантика, клавиатура, dialog для фото, native video controls, reduced motion. Мобильная композиция меняется, лицо героя остаётся над текстом.
Ограничения: работа исключительно внутри проекта; никаких неподтверждённых фактов; MAX и телефон строго из задания; оригиналы не удалять.
