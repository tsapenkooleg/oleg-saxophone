# Олег Цапенко — персональный сайт саксофониста

React 19 · TypeScript · Vite · GSAP / ScrollTrigger. Статический лендинг без сервера, регистрации и автоматического воспроизведения музыки.

## Локальный запуск

```powershell
npm install
npm run dev
```

Открыть **http://localhost:5180**. Отдельный порт выбран, чтобы не конфликтовать с соседними проектами.

```powershell
npm run typecheck
npm run build
npm run preview
```

Production-просмотр: **http://localhost:5181**. На хостинг загружается содержимое `dist/`. Проект рассчитан на размещение в корне домена.

## Основные файлы

- `src/App.tsx` — все секции и анимации.
- `src/components/VideoSection.tsx` — видео, кнопка Play, штатное управление и сообщение об ошибке.
- `src/components/PhotoDialog.tsx` — модальный фотопросмотр, Escape, удержание и возврат фокуса.
- `src/components/ArtistImage.tsx` — responsive WebP, размеры и безопасное состояние при ошибке изображения.
- `src/config.ts` — единое место для контактов и медиа.
- `src/styles.css`, `src/fonts.css` — оформление, адаптивность, локальные шрифты, reduced motion.
- `index.html`, `public/robots.txt`, `public/favicon.svg` — SEO и метаданные.
- `docs/screenshots/` — desktop 1440×900 и mobile 390×844.
- `docs/qa/` — отчёт проверок и Lighthouse.

WebP: полные версии суммарно 588 238 байт; дополнительные варианты шириной 800 px выбираются через `srcSet`. Новое видео `sax_1.mp4` подключено напрямую, размер 46 188 952 байт. Старый оптимизированный `performance.mp4` оставлен как производная копия. Видео не загружается до взаимодействия (`preload="none"`).

Для подготовки производных использовались разовые локальные инструменты в игнорируемой `.tools/`; они не являются зависимостями сайта. Шрифты Cormorant Garamond и Manrope размещены локально, лицензии OFL рядом. SVG-символ MAX взят из официального логотипа на `max.ru`, не заменён произвольной пиктограммой.
